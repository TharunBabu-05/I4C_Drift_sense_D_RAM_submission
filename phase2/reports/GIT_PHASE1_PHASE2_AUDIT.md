### 1. `evaluate.py` — Minor refactor (performance only)

**Change:** Moved model loading outside the evaluation loop (was reloading per pair, now loads once).
Added `gc.collect()` to prevent memory buildup during bulk evaluation.

```diff

+    import torchvision.transforms.functional as TF

+    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
+    model = PyramidSiameseNetwork(encoder_type="resnet").to(device)
+    if os.path.exists(args.checkpoint):
+        model.load_state_dict(torch.load(args.checkpoint, map_location=device))
+    model.eval()
...
-    pred_x, pred_y = master_inference_claude.run_hybrid_pipeline(...)
+    pred_x, pred_y = master_inference_claude.localize_hybrid(model, ...)
+    gc.collect()
```

**Compliance assessment:** SAFE. This is an evaluation-script optimization. The model
architecture, weights, and inference logic are identical. The change avoids reloading
the checkpoint 60 times per evaluation run.
